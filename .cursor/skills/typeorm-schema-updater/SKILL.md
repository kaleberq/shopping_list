# TypeORM Schema Updater

Atualiza schema via entities TypeORM + `database/init.sql`.

## ⚠️ CRITICAL SAFETY RULE ⚠️

- DO NOT run `docker compose down -v` unless the user explicitly asks
- DO NOT drop tables/columns with data without confirmation
- DO NOT read `.env` secrets
- Job ends at **entity + init.sql**; reset de volume é decisão do usuário

## Naming

| Camada | Convenção |
|--------|-----------|
| Tabela | snake_case plural (`shopping_list_items`) |
| Coluna SQL | snake_case (`list_id`, `password_hash`) |
| Property TS | camelCase + `@Column({ name: 'list_id' })` |
| Entity | PascalCase + `Entity` (`ShoppingListItemEntity`) |

## Workflow

1. Verificar pré-requisitos (tabela existe? FK?)
2. Clarificar nullable / default / índice / unique
3. Atualizar entity em `src/**/entities/`
4. Registrar em `forFeature` + `forRoot` `entities`
5. Atualizar `database/init.sql` (`IF NOT EXISTS`)
6. Com `TYPEORM_SYNC=true`, restart do Nest alinha em dev
7. Apresentar checklist — não resetar volume sozinho

## Template — nova tabela

```typescript
@Entity('example_things')
export class ExampleThingEntity {
  @PrimaryGeneratedColumn({ type: 'bigint' })
  id!: string;

  @Column({ type: 'varchar', length: 255 })
  name!: string;

  @CreateDateColumn({ name: 'created_at', type: 'timestamptz' })
  createdAt!: Date;
}
```

```sql
CREATE TABLE IF NOT EXISTS example_things (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

## Checklist

- [ ] Entity criada/atualizada
- [ ] Entity no `forFeature` e no `forRoot`
- [ ] `database/init.sql` atualizado
- [ ] Índices/unique ok
- [ ] Não rodei `down -v` sem pedido
- [ ] Não toquei `.env`

## Output

```
Updated schema:
- Entity: src/.../entities/<name>.entity.ts
- SQL: database/init.sql

Dev: restart npm run start:dev (TYPEORM_SYNC=true).
Fresh DB: docker compose up -d. Reset volume only if confirmed.
```
